HomeLedger — a working household budget site for the Rivera family. Track income and spending across ten categories, keep a monthly budget per category with live progress bars, save towards three goals, and read a six-month report with plain-language takeaways. Everything runs from static files with no network request, works on desktop and on a phone, and stores the household's data only in the browser (localStorage).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Dashboard, Transactions, Budgets, Savings goals and Reports, each reached from the top navigation. Add, edit and delete transactions, filter the ledger, change any budget limit, add funds to a goal or start a new one; the dashboard updates at once.
